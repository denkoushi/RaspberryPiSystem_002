# 減らせる検査

## この画面でできること

自主検査の記録をもとに、検査を減らせるか、増やす必要があるかを確認します。
品番ごとの判定理由を見て、変更の承認や作業条件の変化を記録できます。
ここでの承認は記録だけです。実際の検査方法の変更は、管理画面での変更を待ちます。

## 基本の手順

1. 「期間」で「30日」「90日」「180日」から選び、「工程」で対象を絞ります。
2. 必要に応じて「品番・資源CD」で検索し、一覧から品番を選びます。
3. 「データ量」「公差の余裕」「連続合格」などを見て、判定の理由を確認します。
4. 承認を行う場合は、表示されている「1段減らす」または「1段増やす」を押します。
5. 「承認者の社員タグをタッチ」が出たら、承認者の社員証をかざします。やめる場合は「やめる」を押します。
6. 承認後の表示を確認します。承認だけでその場の検査方法が切り替わるわけではありません。

作業条件の変化を残す場合の手順です。

1. 対象の品番を選び、「変化点」を押します。
2. 変化の種類を選び、記録する人の社員証をかざします。
3. 記録済みの内容は「これまでの変化点」で確認できます。

## よくある困りごととその場の対処

- 「該当する記録がありません」と出たら、期間・工程・検索欄を見直します。判定の絞り込みは「すべて」で確認できます。
- 「品番を選んでください」と出たら、一覧の対象を押します。
- 「1段減らす」「1段増やす」が出ない場合は、変更の対象となる判定が出ていません。選んだ品番の判定理由を確認します。
- 社員証をかざしても承認されない場合は、先に変更のボタンを押し、タグを求める表示が出ているか確認します。
- 承認後も検査方法が変わらない場合は、管理画面での変更待ちの表示を確認します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
