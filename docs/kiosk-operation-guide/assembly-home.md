# 組立

## この画面でできること

製番と台数を選んでロットを登録し、1台ずつ組立作業を始められます。
「着手前」「仕掛中」「完了」の欄で進み具合を確認できます。
「見る」から要領書の閲覧、「記録確認」「製品構成」「訓練」へ移動できます。

## 基本の手順

1. 「製番」に入力し、候補から対象の製番と機種を選びます。
2. 台数を確認します。必要なら台数の横の増減ボタンで直します。台数の入力欄が出た場合は、1〜500の台数を入力します。
3. 発行予定の作業用IDと台数を確認し、台数が書かれた登録ボタンを押します。
4. 「着手前」の対象の台を押します。
5. 「作業者確認」が出たら、実際に作業する人の社員タグをかざします。確認が通ると作業画面へ進みます。
6. 途中の作業は「仕掛中」の対象の台を押して再開します。

## よくある困りごととその場の対処

- 「候補なし」：入力した製番を確かめて、入力し直してください。
- 「手順なし」：その候補ではロット登録できません。「手順を作る」から手順書の一覧へ進めます。
- 登録ボタンが押せない：台数と作業用IDの数が一致しているか確認します。手入力する場合は「ID手入力」を押し、不要なIDを外してから「追加」します。
- 「同じIDは登録できません」：すでに並んでいるIDを確認し、重複しないIDを入力します。
- 「社員タグを確認できませんでした。」：処理が終わってから社員タグをかざし直します。番号の手入力では開始できません。
- ロット一覧の取得に失敗した：一覧右上の丸い矢印ボタンを押し、読み込み直します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
