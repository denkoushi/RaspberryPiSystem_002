# 納期と材料

## この画面でできること

配膳の場所に置いた部品と、まだ置いていない部品を製番ごとに確認できます。
製番の見出しには機種名、エクセルの部品完成日（納期）、照合済みと配膳済みの件数・割合が出ます。

## 基本の手順

1. 「在庫操作」の「配膳の場所」で「納期と材料」を押します。
2. 「一般」「D社」「両方」で製番ボードと同じ区分に切り替えます。最初は「両方」で、選んだ区分は端末に保存されます。
3. 製番ボードに登録済みの製番がボードの順に並び、その後ろに未登録の製番が納期順に並びます。納期は月/日と曜日で表示します。
4. はじめは全製番が閉じています。見出しの「照合済み」「配膳済み」は、その製番の明細件数に対する件数と割合です。配膳済みは棚にある部品です。
5. 製番の見出しを押して明細を開き、もう一度押すと閉じます。「材料未着あり」と出ている製番は、明細の「材料」列でどの部品の材料が未発注・未入荷・一部入荷か確かめます。
6. 置いた部品の行を押すと、配膳の場所でその棚が開きます。まだ置いていない部品は、棚の欄が点線の枠になります。
7. 「足取り」で、その品物が通った工程や棚の記録を見られます。「‹ 配膳の場所へ」で配膳の場所に戻ります。

## よくある困りごととその場の対処

- 「材料の入荷状況を取得できません」と出たら、「再読込」を押します。一覧はそのまま使えます。
- 材料の印は製番一覧の表示後に読み込みます。読み込み後も材料の欄が空の部品は、購買の記録から入荷状況を確認できていません。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
