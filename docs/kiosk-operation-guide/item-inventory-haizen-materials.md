# 納期と材料

## この画面でできること

配膳の場所に置いた部品と、まだ置いていない部品を、エクセルの部品完成日(納期)の順に一覧で見られます。
部品ごとに、材料が入荷済みか、未入荷か、未発注かも分かります。

## 基本の手順

1. 「在庫操作」の「配膳の場所」で「納期と材料」を押します。
2. 上から納期の早い順に並びます。同じ製番の部品はまとまって並びます。
3. 「材料」の列で、材料入荷済・材料未入荷・材料未発注を確かめます。
4. 置いた部品の行を押すと、配膳の場所でその棚が開きます。まだ置いていない部品は、棚の欄が点線の枠になります。
5. 「足取り」で、その品物が通った工程や棚の記録を見られます。
6. 「‹ 配膳の場所へ」で配膳の場所に戻ります。

## よくある困りごととその場の対処

- 「材料の入荷状況を取得できません」と出たら、「再読込」を押します。一覧はそのまま使えます。
- 材料の欄が空のときは、その部品の購買の記録が見つかっていません。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
