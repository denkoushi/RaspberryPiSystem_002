# パレット可視化

## この画面でできること

加工機とパレット番号を選び、そのパレットの部品を確認します。
バーコードを読み取って部品を登録できます。
選んだ部品の上書きや削除、パレット内の全削除もできます。

## 基本の手順

1. 配膳の画面で「パレット」を押します。
2. 「加工機」の一覧から対象の加工機を選びます。
3. 数字ボタンでパレット番号を入力します。入力を直す場合は「←」で1桁消すか、「クリア」で入力を消します。
4. 数字ボタンの下のバーコードのマークを押し、製造番号のバーコードを読み取ります。
5. 登録された部品の一覧を確認します。続けて登録するときは、パレット番号をもう一度入力して読み取ります。
6. 部品を置き換えるときは一覧の対象を押し、「上書」から新しいバーコードを読み取ります。
7. 部品を削除するときは一覧の対象を押し、「選択削除」を押します。「全削除」は表示中のパレット内の部品をすべて削除します。

## よくある困りごととその場の対処

- 「パレット番号をテンキーで入力してからスキャンしてください」と出たら、数字ボタンで番号を入力してから読み取り直してください。
- 「1桁のときは1〜9を押してください」と出たら、「クリア」で消して正しい番号を入れてください。使える番号の範囲は加工機の欄の下で確認できます。
- 「加工機を選択してください」と出たら、加工機を選んでください。
- 「上書」や「選択削除」を押せないときは、一覧から部品を選んでください。処理中は完了を待ってください。
- 「このパレットに部品はありません」と出たら、加工機と入力したパレット番号を確認してください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
