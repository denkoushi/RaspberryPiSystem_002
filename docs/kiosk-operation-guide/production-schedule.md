# 生産スケジュール

## この画面でできること

製番や製造番号で作業を探し、完了・未完了を切り替えられます。
作業の納期や備考を入力し、設備ごとの作業順を確認できます。

## 基本の手順

1. 「検索・資源フィルタ」の右端の絞り込みマークにマウスを乗せ、検索欄を表示します。「製造order番号 / 製番で検索」の欄に番号を入れます。
2. 「検索」を押します。必要に応じて「研削工程」「切削工程」や機種名で絞ります。
3. 対象の行を確認し、作業が終わったら「完了」欄の丸いチェックボタンを押します。もう一度押すと未完了に戻ります。
4. 納期を変えるときは「納期日」欄のカレンダーのボタンを押し、日付を選びます。
5. 備考を入れるときは「備考」欄の鉛筆のボタンを押し、入力して「保存」を押します。

## よくある困りごととその場の対処

- 「検索してください。」と出る：番号を入力して「検索」を押します。
- 「該当するデータはありません。」と出る：番号と絞り込み条件を確認します。「クリア」で条件を戻し、番号を入れ直して検索できます。
- 部品名を選べない：先に機種名を選びます。
- 「手動順番」が押せない：設備を表す「資源CD」を1つだけ選びます。作業順の変更は「手動順番」に切り替え、未完了の行の「資源順番」で行います。
- 読み込み中にボタンを押せない：読み込みが終わるまで待ちます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
