# 通話

## この画面でできること

ほかの端末に電話をかけ、着信に応答できます。
通話中に自分のビデオを有効・無効に切り替えられます。

## 基本の手順

1. 一覧で相手の場所と端末名を確認します。
2. 相手の「📞 発信」を押し、「発信中...」になったら応答を待ちます。
3. 映像を送るときは「📹 ビデオを有効化」を押します。止めるときは「📹 ビデオを無効化」です。
4. 終わるときは「📞 切断」を押します。
5. 「着信」が出たときは「受話」で応答します。出ない場合は「拒否」を押します。

## よくある困りごととその場の対処

- 「接続待機中...」の間は発信できません。接続を待ちます。
- 「相手のキオスクが起動していません」と出たら、相手端末の電源が入り、キオスク画面かサイネージ画面が開いているか確認してから、かけ直します。
- 「通話サーバーに接続できません」と出たら、通信状態を確認し、しばらく待ってかけ直します。
- 「相手は通話中です」と出たら、時間をおいてかけ直します。
- 「相手が切断されました」と出たら、相手の端末の状態を確認してからかけ直します。
- 「発信可能な端末がありません」と出て相手を選べない場合は、端末名と表示内容をお問い合わせへ送ってください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
