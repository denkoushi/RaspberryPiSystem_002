# 写真撮影持出

## この画面でできること

社員証をかざすと、写真を撮って持出を登録します。
右側の「持出一覧」から返却や持出の取消ができます。

## 基本の手順

1. 「従業員タグをスキャンしてください」と出たら、社員証をかざします。
2. 「カメラを起動中...」「写真を撮影しています」の間は待ちます。
3. 「登録完了」と、自分の名前を確認します。
4. 返すときは「持出一覧」で対象を確認し、「返却」を押します。
5. 登録を取り消すときは「取消」を押し、対象を確認して「取り消す」を押します。やめるときは「キャンセル」です。

## よくある困りごととその場の対処

- 「エラー」が出たら「リセット」を押し、待機表示に戻ってから社員証をかざし直します。
- 「写真の撮影に失敗しました」と出た場合も、リセットしてやり直します。繰り返す場合は表示内容をお問い合わせへ送ってください。
- 撮影中は「リセット」を押せません。撮影が終わるまで待ちます。
- 計測機器や吊具のタグでは、それぞれの持出画面へ移ります。写真で登録するときは社員証を使います。
- 「送信中…」「取消中…」の間は、返却や取消の処理が終わるまで待ちます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
