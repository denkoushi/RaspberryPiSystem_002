# 在庫の準備

## この画面でできること

品物の写真や置き場所、タグ、最初の在庫数を登録できます。
棚・引き出しの準備、数量タグ・補充タグの登録、品物の編集もできます。

## 基本の手順

1. 「4桁のパスワード」を数字ボタンで入力します。4桁そろうと自動で確認されます。
2. 「登録待ち」で候補を選び、写真を確認して「新規登録」を選びます。
3. 「名前・工具情報」「単位」を確認し、「置き場所」でエリア・棚・引き出しを選びます。
4. 置き場所を選んだ後、品物のタグをかざし、「最初の数」を入力します。
5. 「登録する」を押し、完了画面に出た番号をタグと引き出しに書きます。「次へ」で次の候補へ進めます。
6. 作業が終わったら「ロック」を押します。在庫操作へ戻るときは、パスワード入力画面の「やめる」を押します。

既存の品物に写真を足すときは「既存のアイテムに写真を追加」を選びます。
棚の準備は「棚・引き出し」、数量タグ・補充タグの登録は「NFCタグ」、登録済みの品物を直すときは「アイテム編集」を開きます。

## よくある困りごととその場の対処

- 「パスワードが違います」と出たら、正しい4桁を入力し直します。
- 「確認できませんでした。ネットワークを確認してください」と出たら、通信状態を確認します。
- 写真メールの取り込みに失敗したときは「もう一度取り込む」を押します。
- 「登録待ちの候補はありません」と出て、登録済みの品物を直したい場合は「アイテム編集」を使います。
- タグを読み違えたときは「読み直す」を押します。
- 写真からの情報が「読み取れませんでした」と出たら、「名前」「型式」「メーカー」などを手で入力します。
- 「登録する」を押せないときは、画面に出ている残りの入力・選択を確認します。
- 棚に「引き出しあり」、引き出しに「使用中」と出ている場合は削除できません。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
