# ポータル

## この画面でできること

キオスクの各画面が大きなカードで並び、押すとその画面へ移ります。
カードは「持出・返却」「生産」「品質・図面」「在庫・購買」「稼働・連絡」のまとまりごとに並びます。

## 基本の手順

1. 開きたい画面のカードを押します。
2. ほかの画面からポータルに戻るときは、上のタブ列の先頭にある「ポータル」を押します。
3. 大きな画面で見るときは「50インチ表示」を押します。もう一度押すと元の大きさに戻ります。この切り替えは端末ごとに覚えます。
4. この端末に出すカードを変えるときは、歯車のボタンを押します。「この端末に出すカード」で出したいカードに印を付け、「保存」を押します。「全部」で全部に印が付き、「なし」で全部の印が外れます。変えずに閉じるときは「やめる」を押します。
5. 起動したときにポータルを開くようにするには、ポータル画面で家のアイコンを押します。

## よくある困りごととその場の対処

- 「出すカードがありません。上の歯車で選んでください」と出たら、歯車のボタンを押してカードに印を付け、「保存」を押します。
- 「保存できませんでした。接続を確認してもう一度お試しください。」と出たら、通信状態を確認し、もう一度「保存」を押します。
- 「ポータル設定を読み込めませんでした。接続を確認してください。」と出たら、通信状態を確認し、しばらく待ってから画面を開き直します。
- 使いたい画面のカードが無いときは、歯車のボタンで、そのカードが外されていないか確認します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
