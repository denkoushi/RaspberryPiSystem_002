# 要領書

## この画面でできること

要領書を検索し、選んだ文書を画面で読めます。
1ページ表示・見開き表示や、拡大・縮小を切り替えられます。

## 基本の手順

1. 「ファイル名・タイトルで検索」に探す言葉を入力します。
2. 必要なら「取込元:」で「すべて」「手動」「Gmail」を選びます。
3. 一覧で読みたい文書を押し、右側をスクロールして読みます。
4. 表示を変えるときは「表示オプション」の右のスライダー型の印にマウスを載せます。
5. 「1ページ」「見開き」を選びます。「＋」「−」で大きさを変え、「リセット」で戻せます。

検索欄の横の「スキャン」から、バーコードで検索することもできます。

## よくある困りごととその場の対処

- 「表示する要領書がありません」と出たら、検索語を見直すか消し、取込元を「すべて」にします。
- 一覧が隠れているときは、表示オプションを開き、一覧を表示する印を押します。
- 見開きや拡大の操作が見えないときは、表示オプション右の印にマウスを載せます。
- 横幅いっぱいの表示では拡大・縮小できません。表示オプションで標準幅の印に切り替えます。
- 「一覧の取得に失敗しました」「文書の読み込みに失敗しました」が続く場合は、探していた文書名をお問い合わせへ送ってください。
- 「ページ画像がありません（PDFの再変換が必要な場合があります）」と出たら、文書名と表示内容をお問い合わせへ送ってください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
