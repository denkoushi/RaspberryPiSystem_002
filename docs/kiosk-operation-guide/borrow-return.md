# 持出フロー

## この画面でできること

工具のタグと社員証をかざして、持出を登録します。
右側の「持出一覧」から返却や持出の取消ができます。
計測機器や吊具のタグをかざすと、それぞれの持出画面へ移ります。
在庫用のタグをかざすと、在庫の画面へ移ります。

## 基本の手順

1. 持ち出す工具のタグをかざします。「① アイテム」に読み取った番号が出ます。
2. 社員証をかざします。「② 社員」に番号が入り、登録が進みます。
3. 「登録完了」と、持ち出した品物・社員の名前を確認します。
4. 返すときは「持出一覧」で対象を探し、その品物の「返却」を押します。
5. 持出の登録を取り消す場合は「取消」を押し、対象を確認して「取り消す」を押します。やめる場合は「キャンセル」を押します。

## よくある困りごととその場の対処

- 読み取りをやり直したいときは「リセット」を押し、工具のタグと社員証をかざし直します。
- 「タグ未登録（アイテム）」や「タグ未登録（社員）」が出たら、使ったタグと社員証を確認します。登録の確認はお問い合わせへ送ってください。
- 「返却一覧の取得に失敗しました」が出たら、「リセット」で画面を読み直します。
- 「送信中…」「取消中…」の間は処理が終わるまで待ちます。
- 「現在貸出中のアイテムはありません。」と出る場合は、一覧から返却する品物がありません。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
