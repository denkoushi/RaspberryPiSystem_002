# 在庫操作

## この画面でできること

品物の払い出し・補充を記録し、現在の在庫数を確認できます。
実物の数と違う場合は、数えた数に直せます。

## 基本の手順

1. 品物のタグをかざすか、一覧の品物を押します。「番号で開く」で番号を入力し「開く」を押す方法もあります。
2. 品名・置き場所・「現在庫」を確認します。
3. 「払い出し」または「補充」を選びます。
4. 数量タグをかざすか、数量ボタンを押します。押すとすぐに記録されるので、先に数を確認してください。
5. 数量ボタンにない数は「ほかの数」で入力して「決定」を押します。
6. 補充が終わると払い出しに戻ります。続ける場合は、品物と払い出し・補充のどちらになっているかを確認します。
7. 一覧へ戻るときは「一覧へ」を押します。

タグだけで補充する場合は、補充タグ、品物のタグ、数量タグの順にかざします。

## よくある困りごととその場の対処

- 「先にアイテムNFCタグを読み取ってください」と出たら、品物のタグからやり直します。
- 「この番号の品物はありません」と出たら番号を確かめて入力し直すか、一覧から選びます。
- 「一覧を取得できませんでした」と出たら「もう一度」を押します。
- 「在庫が足りません」と出る場合や数量ボタンを押せない場合は、「現在庫」と実物の数を確認します。
- 「通信できませんでした。在庫数を確かめてください」「数が変わりました」と出たら、まず表示された在庫数を確認します。
- 実物と数が違うときは「数が合わないときは直す」を押し、「数えた数」を入力して、入力した数へ直すボタンを押します。やめるときは「やめる」です。
- 直前の記録を取り消すときは、品名と数量が出ている「取消」のボタンを確認して押します。
- 一覧で品物が見つからないときは、「エリア」や「棚」の「すべて」で絞り込みを外します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
