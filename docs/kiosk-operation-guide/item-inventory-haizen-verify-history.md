# 照合の履歴

## この画面でできること

配膳スマホで移動票と現品票を照合した結果を、新しい順に一覧で見られます。
不一致や未登録だった照合を探し、その品物の足取りを開けます。

## 基本の手順

1. 「在庫操作」の「配膳の場所」で「照合の記録」を押します。
2. 上の「今日」「7日」「30日」で、見る期間を選びます。
3. 「全部」「一致」「不一致」「未登録」「照合できず」で結果を絞ります。端末ごとに見るときは端末名を、全部に戻すときは「全端末」を押します。
4. 番号で探すときは、キーで製造オーダーや製番を入れます。「⌫」で1字、「C」で全部消せます。
5. 行を押すと、右にその照合の中身が出ます。「足取り」を押すと、その品物の足取りの画面が開きます。
6. 「‹ 配膳の場所へ」で配膳の場所に戻ります。

## よくある困りごととその場の対処

- 照合したはずの記録が出ないときは、配膳スマホが Wi-Fi につながっているか確かめます。記録はスマホに貯まり、Wi-Fi のときに送られます。
- 「記録はありません」と出たら、期間を「30日」にするか、番号の一部だけで探し直します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
