# 自主検査

## この画面でできること

移動票や品番から検査対象を探し、図面を見ながら測定値を記録します。
途中の自主検査を再開したり、検査員が再測定・最終判定を行ったりできます。
「部品番号スキャン」から作業要領書を探すこともできます。

## 基本の手順

1. 一覧で「移動票スキャン」を押して移動票を読み取ります。手入力なら「製造order・製番・品番」に2文字以上入れるか、「資源CD」で探します。
2. 対象を選び、「検査方法を選択」が出たら、必要に応じて「検査資源」を選んで「デジタル入力」を押します。
3. 測定画面で、測定する人の社員証を先にかざします。氏名を読み取るまで測定値は選べません。
4. 何件目の入力かを選び、図面上の測定点を押して測定値を入れます。「次の測定点」で次へ進めます。
5. 使用前点検が必要な場合は、社員証を読み取った後に計測機器のタグをかざします。計測機器の点検画面へ移ります。
6. 必要な測定点を入力し、「入力を保存」を押します。必要な件数をそれぞれ保存します。
7. 入力と点検をそろえ、表示される「自主検査を完了」または「測定を終了」を押します。承認が必要な記録は「記録確認・承認」で確認します。

検査員が再測定する場合の手順です。

1. 検査記録確認画面から、表示された「検査員測定へ」などの案内に進みます。
2. 検査員本人の社員証をかざし、作業者の保存が済んでいる入力件を選び、再測定値と必要な点検をそろえて保存します。
3. 作業者側で不合格だった測定点には最終の合否を入れ、必要件数の保存後に「最終判定を確定して完了」を押します。

## よくある困りごととその場の対処

- 一覧で氏名のタグが反応しないときは、先に「氏名スキャン」を押してから社員証をかざします。氏名で絞った結果を解除するには「クリア」を押します。
- 「仕掛中の自主検査はありません。検索して新規開始できます。」と出たら、移動票を読み取るか、番号や資源で検索します。
- 読み取った移動票の番号が不正と表示されたら、移動票を読み取り直します。
- 「自主検査の開始情報が不足しています。一覧または順位ボードから開き直してください。」と出たら、一覧または順位ボードで対象を選び直します。
- 「未入力の測定点があります。すべて入力してから保存してください。」と出たら、選択中の入力件の空欄を埋めます。
- 「公差外の測定値です」と出たら、値を確認します。入力を直す場合は「再入力」、値が正しく合格範囲外だった場合は「公差外のまま進む」を押します。
- 保存や完了が押せない場合は、画面の案内を確認します。未保存の入力を保存し、測定者と計測機器の点検の不足を確認します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
