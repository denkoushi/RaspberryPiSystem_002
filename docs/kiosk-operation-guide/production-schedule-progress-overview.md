# 進捗一覧

## この画面でできること

登録した製番ごとに、部品の納期と工程の進み具合を確認できます。
製番を選び、見たいものだけを表示できます。

## 基本の手順

1. 一覧で、確認したい製番と機種名を探します。
2. 部品名の横に出る納期と工程を確認します。
3. 表示を絞るときは製番フィルタを開き、見たい製番を選びます。「全てON」でまとめて表示できます。
4. 最新の状態を確認するときは「手動更新」を押し、「更新中...」が消えるまで待ちます。

## よくある困りごととその場の対処

- 登録製番がないという案内が出る：生産スケジュール画面で製番を入力して検索し、登録してから戻ります。
- フィルタで非表示にしているという案内が出る：製番フィルタで見たい製番を選ぶか、「全てON」を押します。
- 「進捗一覧の取得に失敗しました。」と出る：「手動更新」を押して再取得します。
- 進捗を表示できる製番がないという案内が出る：時間をおいて「手動更新」を押します。
- 「手動更新」が押せない：更新中は押せません。終わるまで待ちます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
