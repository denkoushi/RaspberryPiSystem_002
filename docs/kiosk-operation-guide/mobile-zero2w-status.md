# 棚番配膳（Zero2W）

## この画面でできること

棚の端末から記録された配膳の一覧を確認します。
棚番、製造番号、日程との照合状態、製番、品番、更新日時を確認できます。
この画面は全棚の最新50件を表示します。

## 基本の手順

1. 配膳の画面で「棚番配膳一覧（Zero2W）」を押します。
2. 「一覧を更新」を押し、最新の一覧を読み込みます。
3. 棚番と製造番号を見て、確認したい記録を探します。
4. 「日程一致」または「未照合」の表示と、更新日時を確認します。
5. 「戻る」を押すと、配膳の画面に戻れます。

## よくある困りごととその場の対処

- 配膳の画面で選んだ棚だけにならない場合も、この画面では全棚の一覧が表示されます。棚番と製造番号で対象を確認してください。
- 「配膳一覧の取得に失敗しました。更新を再度お試しください。」と出たら、もう一度「一覧を更新」を押してください。
- 「該当する配膳記録はありません。」と出たら、記録がまだ表示されていません。「一覧を更新」で再確認できます。
- 「一覧を更新」を押せない間や「読み込み中…」と出ている間は、読み込みが終わるまで待ってください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
