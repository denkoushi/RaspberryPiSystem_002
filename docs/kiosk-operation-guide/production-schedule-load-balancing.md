# 負荷調整

## この画面でできること

設備ごとの作業量を月別に見て、能力を超えているところを確認できます。
「外注」「移管」「後ろへ」で、作業を動かした場合を試算できます。試算では実際の作業予定は変わりません。
設備の月あたりの能力は、この画面で入力して保存できます。

## 基本の手順

1. 上側の矢印で期間を選びます。必要に応じて機種を選びます。
2. 設備と月が交わるマスを押し、右側で作業の内訳を確認します。
3. 試算したい行で「外注」「移管」「後ろへ」を押します。「移管」では移す先を選びます。
4. 「試算」の「超過計」で、変更前と変更後を比べます。
5. 試算を戻すときは「↶ 1つ戻す」、全部戻すときは「クリア」を押します。

## よくある困りごととその場の対処

- 「能力未設定」がある：対象の設備の月のマスを選び、「能力 ✎」を押します。月あたりの時間を入力して「保存」を押します。
- 能力の「保存」が押せない：空欄にせず、0〜10000の数値を入れます。保存中は終わるまで待ちます。
- 「移管先がありません」と出る：移管先は選べません。「外注」や「後ろへ」で別の試算を確認できます。
- 「この月の負荷はありません」と出る：別の月のマスを選びます。
- 月別の表に入っていない作業を見たい：「未配分」を押すと、「着手日なし」「納期なし」などの理由を確認できます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
