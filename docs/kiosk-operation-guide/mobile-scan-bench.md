# 読取速度テスト（配膳スマホ）

## この画面でできること

配膳スマホでバーコードが読めるまでの秒数を測ります。
「今の読み方」と「高速読取」、「今と同じ画質」と「高画質」を切り替えて比べられます。
この画面で読んだ内容は登録されません。

## 基本の手順

1. 「今の読み方」か「高速読取」を押して、読み方を選びます。
2. 「今と同じ画質」か「高画質」を押して、画質を選びます。
3. 「カメラ開始」を押し、カメラの許可を求められたら許可します。
4. 「読む」を押し、移動票などのバーコードをカメラに映します。
5. 読めると秒数と値が表に出ます。「次を読む」で続けて測ります。
6. 回数、中央値、最速、最遅、読めずの数を見て、読み方ごとに比べます。

## よくある困りごととその場の対処

- 「この端末では高速読取が使えません」と出たら、その端末では「今の読み方」だけで測ってください。
- 15秒たっても読めないと「読めず」になります。明るい所で、バーコードを枠いっぱいに映して「次を読む」を押してください。
- 「読取エラー。もう一度お試しください」と出たら、もう一度「読む」を押してください。
- 測り直したいときは「記録を消す」を押します。

## それでも直らないとき

この画面にはお問い合わせのボタンがありません。
配膳の画面に戻って「お問い合わせ」から送るか、管理者に端末名と、何をしたら何が出たかを伝えてください。
