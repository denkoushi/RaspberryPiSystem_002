# 組立作業

## この画面でできること

作業中の製番と機種を確認し、要領書をめくって閲覧できます。
締付けの記録、チェックの進み具合を確認し、作業完了を記録できます。

## 基本の手順

1. 「作業者確認」が出たら、再開する人の社員タグをかざします。画面を読み込み直したときや直接開いたときにも確認が必要です。
2. 画面上部の製番と機種を確認します。
3. 要領書は「前手順」「次手順」でめくります。「全手順」で一覧を開き、「現在の丸数字へ」で現在の締付箇所の表示に戻れます。
4. 一部を切り出した表示では「全体を一時表示」で元のページ全体を確認し、「矩形へ戻る」で戻ります。
5. 要領書の丸いチェックを押すと確認済みを切り替えられます。「チェック進捗」で必須項目の数を確認します。
6. 「トルクレンチ接続」が出ている場合は、使用するレンチを選び、画面の案内に沿って現物を確認して接続します。「製造番号と現物設定を確認」がある場合は、確認後に「このレンチを使用開始」を押します。
7. 「トルク値」の入力欄が出ている場合は、測定した値を入力し、「手入力」を選んで「トルク記録」を押します。
8. 「履歴」で締付けの記録を確認します。工程を終えたら、押せる状態の「次工程へ」で進みます。
9. 全ての締付けと必須チェックを終えたら「作業完了」を押し、「作業を完了しました。」を確認します。「組立へ戻る」で戻れます。

## よくある困りごととその場の対処

- 「社員タグを確認できませんでした。」：確認処理が終わってから、社員タグをかざし直します。
- 「要領書の取得に失敗しました。」：「再試行」を押します。
- 「表示できる要領書ページがありません」：この画面では閲覧できるページがありません。「組立へ戻る」で戻れます。
- 「次手順」が押せない：最後の手順です。「前手順」か「全手順」で見たい手順へ戻ります。
- 「作業完了」が押せない：締付けと必須チェックの進み具合を確認します。「締付が未完了です。」など、ボタン付近の案内を確認してください。
- 記録をやり直す必要がある：「やり直し」で確認画面を開けます。「やり直す」を押すと、そのエリアの記録を消して最初からになります。取りやめる場合は「キャンセル」を押します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
