# 購買照会

## この画面でできること

注文番号のバーコードをカメラで読み取り、注文の内容を確認します。
結果には機種、製番、着手日、品名、品番、個数が表示されます。

## 基本の手順

1. 「スキャン」を押します。
2. 「バーコードをスキャン」が開いたら、注文番号のコードをカメラに向けます。
3. 10桁の注文番号を読み取ると「照会中…」になります。結果が出るまで待ちます。
4. 別の注文を調べるときは、もう一度「スキャン」を押します。
5. 配膳画面へ戻るときは「← 配膳に戻る」を押します。

## よくある困りごととその場の対処

- 注文番号の欄は手入力できません。「スキャン」で入力します。
- 読み取り後に照会が始まらないときは、10桁の注文番号か確認し、正しいコードを読み直します。
- 「データがありません」と出たら、読み取った番号を確認します。違う番号なら読み直します。
- 「カメラを使えません」と出たら「閉じる」で戻ります。再度スキャンしても同じならお問い合わせへ送ってください。
- 読み取れないまま画面が閉じたときは、もう一度「スキャン」で開始します。読み取り画面は30秒で閉じます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
