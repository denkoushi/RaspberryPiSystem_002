# 手順書

## この画面でできること

手順書のページを選び、文章や画像、図形を追加・編集できます。
変更を保存してから公開できます。公開済みの文書を直す場合は、改版の下書きで編集します。

## 基本の手順

1. 「暗証番号」が出たら番号を入力します。入力後も画面が閉じない場合は「OK」を押します。
2. 左側の小さなページ画像を押して、編集するページを選びます。
3. 「文字を置く」や「図形を置く」を押して追加します。追加したものを選び、文章、色、位置、大きさを直します。
4. 間違えた変更は「元に戻す」で戻せます。内容を確認して「保存する」を押します。
5. 使用する内容として公開するときは「公開する」を押します。
6. 「社員タグで承認して公開」を選び、承認者の社員タグをかざします。表示された名前を確認して「承認して公開する」を押します。
7. 締付テンプレート向けには「パスワードで公開(締付テンプレート向け)」も選べます。内容を確認して「公開する」を押します。

## よくある困りごととその場の対処

- 「違います」：入力した暗証番号を訂正します。「認証の期限が切れました。」の場合も、暗証番号を入力し直します。
- 「保存する」が押せない：変更がない場合は保存できません。追加した文章が空になっていないかも確認します。
- 「公開する」が押せない：未保存の変更があれば先に「保存する」を押します。
- 「編集の予約を取得できていません。」：「予約を再取得」を押します。他の端末が編集中と表示された場合は、画面に表示された編集者を確認します。
- 「保持内容を再保存」が出た：未保存の内容を残して再保存できます。「最新を再読込（保持内容を破棄）」は、保持している変更を捨てて最新の内容に置き換える操作です。
- 「端末に残った下書き」が出た：前回の途中内容を使う場合は「復元」を選び、確認して保存します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
