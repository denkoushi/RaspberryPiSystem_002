# 手動順番

## この画面でできること

端末ごとの作業を見比べ、選んだ端末の作業順を変えられます。
上側に端末ごとの一覧、下側に編集する作業の一覧が出ます。

## 基本の手順

1. 上側で工場を選び、変更したい端末の「編集」を押します。
2. 「編集中」が付いた端末を確認します。下側の見出しの右端の絞り込みマークにマウスを乗せると検索欄が出ます。番号を入力して「検索」を押します。
3. 設備を表す「資源CD」を1つだけ選び、「手動順番」に切り替えます。
4. 未完了の行の「資源順番」で順番を選びます。「保存中…」が消えるまで待ちます。
5. 別の端末を変更するときは、その端末の「編集」を押してから操作します。

## よくある困りごととその場の対処

- 下側に端末を選ぶよう案内が出る：上側の対象端末の「編集」を押します。
- 「資源未割り当て」と出る：「資源」が表示されている場合は押し、「候補」から設備を選びます。「割り当て順（上が優先）」を確認して「保存」を押します。
- 「手動順番」が押せない：「資源CD」を1つだけ選んでください。完了済みの行では順番を変更できません。
- 「保存に失敗しました」と出る：対象端末と現在の順番を確認し、もう一度変更を試します。
- 「表示できる端末がありません。」と出る：選択している工場を確認します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
