# 手順書

## この画面でできること

「手順書」と「テンプレート」を切り替えて、文書や作業用の設定を探せます。
手順書の内容確認、ファイルの登録、公開、編集画面への移動ができます。

## 基本の手順

1. 「手順書」を選び、「名前で検索」に名前を入力します。「全て」「公開」「下書き」「未使用」で絞り込めます。
2. 対象の行の「内容確認」または「内容確認・公開」を押し、各ページを確認します。「閉じる」で一覧に戻ります。
3. ファイルを登録するときは「＋ ファイルから登録」を押し、「手順書名」を入力して「ファイル」を選びます。「先頭ページを確認」で確認し、「下書きとして登録」を押します。
4. 登録後は全ページを確認します。公開する場合は「管理パスワード」を入力し、「確認して公開」を押します。
5. 作業用の設定を探すときは「テンプレート」を選び、「全体検索」や「機種名」で絞り込みます。対象の「改版」から編集画面を開けます。
6. 新しく作る場合は「＋ 手順書から作る」を押し、公開済みの手順書を選びます。
7. 「組立へ戻る」で組立画面へ戻ります。

## よくある困りごととその場の対処

- 「条件に合う手順書はありません。」：検索する名前を短くするか消し、状態を「全て」にして確認します。
- 「条件に合う組立テンプレートはありません。」：検索条件を消すか、×ボタンで条件を解除します。旧版も探す場合は「無効化済みも表示」を選びます。
- 「使える手順書はありません。」：作成元を選ぶ画面では公開済みの手順書だけが対象です。検索語を見直し、一覧で公開状態を確認します。
- 「下書きとして登録」が押せない：手順書名とファイルを確認し、先頭ページの確認を済ませます。
- 一覧を取得できない：丸い矢印の「再読込」ボタンを押します。
- 「使用中は削除できません」：使用先がある手順書です。一覧の使用先を確認してください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
