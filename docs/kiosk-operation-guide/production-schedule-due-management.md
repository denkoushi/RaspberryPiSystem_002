# 納期管理

## この画面でできること

製番ごとの納期日や、部品を進める優先順位を設定できます。
部品の工程進捗を見たり、備考を書いたりできます。
全体の順位や、今日の計画順も確認できます。

## 基本の手順

1. 「製番を検索」に製番を入力して「登録」を押します。登録済みなら、その製番のボタンを押します。
2. 「部品優先順位（製番単位）」で、対象の部品を確認します。
3. 納期を変えるときは、納期日が表示されたボタンを押し、カレンダーの日付を押します。「前月」「次月」で月を変えられます。
4. 部品の順番を変えるときは「↑」「↓」で動かし、「優先順位を保存」を押します。
5. 備考を書くときは「備考」欄の「編集」または記入済みの文を押します。100文字以内で入力して「保存」を押します。

## よくある困りごととその場の対処

- 「製番を選択してください。」と出るときは、一覧の製番を押します。まだ登録していなければ、製番を入力して「登録」を押します。
- 部品の並び替えや「優先順位を保存」が使えないときは、資源の絞り込みを「資源CD: 全件」に戻します。保存中の場合は、終わるまで待ちます。
- 一番上の部品は「↑」、一番下の部品は「↓」で動かせません。動かせる方向のボタンを押します。
- 「順序を保存」が押せないときは、今日の計画順に製番があるか確認します。順番を変えていない場合や、保存中も押せません。
- 「自動生成に失敗しました。再実行してください。」と出たときは、表示されている「生成/再生成して保存」または「自動生成して保存」をもう一度押します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
