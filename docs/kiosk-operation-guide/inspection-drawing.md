# 検査図面

## この画面でできること

検査に使う図面を探し、測る位置や合格範囲を設定できます。
図面付きの記録表では、測定点を選んで測定値を入力できます。
帳票を開くボタンがある場合は、図面と測定値記録欄を印刷できます。

## 基本の手順

1. 一覧の「品番」「図面名」や「資源CD」、工程で対象を絞ります。
2. 既存の設定を直すときは「編集」を押します。登録済みの図面から新しく設定するときは、図面の行の「新規」を押します。
3. 作成画面では、品番・工程・資源を確認し、図面を選びます。図面を変更すると、それまでの測定点が消えるため、確認表示を読んでから進めます。
4. 「丸数字」を選び、図面上の測る位置を押します。「名称」を選び、数値で測る点は図面に合わせて基準値や公差を設定します。
5. 必要な点をそろえて「保存」を押します。複数の資源をまとめた図面では、「保存範囲」も確認します。
6. 記録表を開いている場合は、図面上の点を選んで測定値を入れます。社員証をかざし、作業者名を確認して「確定」を押します。

印刷する場合の手順です。

1. 一覧の「帳票」、編集画面の「保存済み帳票」、または自主検査の「帳票紙印刷」から帳票を開きます。
2. 図面の読み込みを待ち、「印刷プレビュー」を押します。1枚目は図面、2枚目以降は測定値記録欄です。
3. 編集中の変更を帳票に反映する場合は、先に図面を保存してから帳票を開き直します。

作成画面の「テスト入力」「ガイド試行」は試し操作用で、測定記録としては保存されません。

## よくある困りごととその場の対処

- 「条件に合う検査図面はありません。」と出たら、検索条件を見直すか「リセット」で絞り込みを外します。「再読込」で一覧を取得し直せます。
- 図面の「新規」が押せない場合は、有効な設定がすでにあります。右の一覧から「編集」を押します。
- 「図面上に測定点を1つ以上置いてください。」と出たら、「丸数字」を選んで測る位置を押します。
- 「すべての測定点に名称を入れてください。」と出たら、各点の「名称」を確認します。
- 「履歴版は閲覧のみです。編集するには有効化してください。」と出たら、古い版を見ています。閲覧だけなら変更せず、編集する対象の版を確認します。
- 記録表で「表形式の測定画面を開く」が出たら、そのリンクから表形式で入力できます。
- 印刷画面が「図面読込中…」の間は待ちます。「このテンプレートには印刷用の図面が設定されていません。」と出たら、一覧へ戻って対象の図面を確認します。

## それでも直らないとき

印刷画面からは、先に元の画面へ戻ってください。
画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
