# 製番ボード

## この画面でできること

研削・切削の作業を、製番ごと、または設備の番号ごとに確認できます。
表示したい製番を登録し、未完了の作業の割当先や日付をまとめて変更できます。
「元割当」で元の内容を確認し、「別割当」で変更します。

## 基本の手順

1. 「研削」または「切削」を選びます。
2. 件数が付いた左端の「製番」を押して、製番の登録欄を開きます。
3. 「機種」を押して機種名の数字を入力するか、製番の入力欄に製番を入力します。候補にチェックを付け、「登録」を押します。
4. 「登録製番（OR）」で表示する製番を選び、登録欄の閉じるボタンを押します。
5. 表示の「製番」または「資源CD」を選びます。「未完」「両方」「完了」で進み具合を絞れます。
6. 変更するときは「別割当」を選び、対象の作業にチェックを付けて「一括変更」を押します。製番ごとの表示では、製番を押すと明細を開けます。
7. 「資源CD」で割当先を選びます。日付を変える場合は「指定日」で日付を選ぶか、「+暦日」で加える日数を入力します。変えない項目は「変更なし」のままにします。
8. 対象件数と下部の内容を確認して「適用」を押します。取りやめるときは「キャンセル」を押します。

## ガントで日程を確認する

- 上部の「ガント」を押すと、表示中の作業を日付の横軸で確認できます。もう一度押すと元の表示に戻ります。
- 「1日」「2日」「4日」「1週」「2週」「4週」「8週」で横軸の幅を選びます。「1日」では画面の幅に10時間分を出し、1時間ごとの目盛りを付けます。開いたときと「1日」を押したときは、今の1時間前の正時から出します（8時より前にはしません）。2日・4日では、8時・17時・20時の目盛りが出ます。ボードは毎回「資源CD」「1日」で開きます。横に動かしたあとでも、幅ボタンを押すと（いま選んである物をもう一度押しても）今日の位置に戻ります。ガント右下の「‹」「›」で2時間ずつ戻る・進むことができます。時刻が次の1時間に入ると（毎時0分）、ガントは自動で今日の位置（「1日」なら今の1時間前の正時）に戻ります。
- 「納期から」では棒の右端が納期です。青は予定、赤は納期超過、灰色は完了です。所要時間が分からない作業は「所要不明」、納期がない作業は「納期なし」と表示されます。
- 棒を押すと作業を選べます。「一括変更」も使えます。完了した作業は選べません。
- 「納期から」の「別割当」では、未完了の棒を左右へ動かし、指を離すと納期を変更できます。前へ動かす場合は今日より前には変更できません。「元割当」では棒を動かせません。
- 「資源CD」表示の「8H」「10H」「24H」で、設備ごとの1日の稼働時間を選びます。この設定は全端末で共有され、棒の長さに反映されます。土日も日数に含まれます。「今日から」では、8Hは8:00〜17:00、10Hは8:00〜19:00に、休み時間（10:10〜10:20、12:10〜12:50、14:50〜15:00）を除いて作業を並べます。休み時間は暗い帯を出さず、棒がその分だけ後ろへ延びます。稼働時間の外（夜と朝）だけ暗く表示します。棒には品名と詳しい情報を、それぞれ2行まで折り返して出します。24Hは休みなしです。
- 「納期から」で同じ部品の次の工程が前の工程の終了より早く始まると、赤い斜線と「⚠」が付きます。「重なり」の件数は重なる工程の組数です。押すたびに該当する行へ移動します。
- 重なりの確認対象は、現在ボードに表示している工程だけです。表示していない製番や絞り込みで隠れた工程は含みません。

- 最初は「今日から」で、今からできる順番を表示します。「納期から」で従来の納期基準の表示に戻ります。選んだ並べ方はこの端末に記憶されます。
- 「今日から」の「資源CD」では、バーを左右へドラッグすると作業の順番を変えられます。赤は遅れ見込みです。完了した作業は「納期から」で確認します。
- 「別割当」の「⇅ 納期順」で納期の早い順に並べます。朝まで・今日中の作業は先頭に残り、順番はほかの端末にも反映されます。
- 「↶ 戻す」で、この端末で直前に変えた順番へ戻せます。バーを押すと着手・終了の見込みを確認できます。

棒にマウスを乗せると次にやる順が出て、カードのドラッグで順番を入れ替えられる。1日と2日では、棒に製番・品番・個数・機種名も出る。

## よくある困りごととその場の対処

- 「登録製番がありません。」と出る：製番を検索し、候補を選んで登録してください。
- 「該当する候補はありません。」と出る：入力した機種名の数字や製番を確認してください。完了した製番も探す場合は「完了表示」にチェックを付けます。
- 「登録上限50件を超えるため登録できません。選択を減らしてください。」と出る：候補のチェックを減らしてください。
- 「一括変更」を押せない：「別割当」に切り替え、未完了の作業を選んでください。読み込み中や保存中は、終わるまで待ちます。
- 「適用」を押せない：割当先か日付の変更方法を選んでください。両方が「変更なし」のままでは適用できません。
- 「加算日数は1以上の整数で入力してください。」と出る：小数を使わず、1以上の日数を入力してください。
- 「表示中のデータが更新されています。最新状態を取得してから対象を選び直してください。」と出る：「最新状態を取得して閉じる」を押し、対象を選び直して変更してください。
- 「一覧の追加取得に失敗しました。再読み込みしてください。」と出る：画面を再読み込みしてください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
