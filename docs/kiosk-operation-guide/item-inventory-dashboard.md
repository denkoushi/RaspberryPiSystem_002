# 在庫の集計

## この画面でできること

工具の持出数、よく使う工具、在庫が少ない工具、金額を確認できます。
メーカー名や工具の種類の書き方の違いを、ひとつの名前にまとめることもできます。

## 基本の手順

1. 「在庫操作」の上部にある「集計」を押します。
2. 鍵がかかっているときは「4桁のパスワード」を入力します。「在庫の準備」と同じパスワードです。
3. 上の「4週」「12週」「半年」「1年」で期間を選び、場所の欄で加工機を選んで絞り込みます。
4. 「表記ゆれ」に候補が出たら、同じものなら「〇〇 にまとめる」を、違うものなら「別のもの」を押します。
5. 金額を出すには「単価を入れる」を押し、「アイテム編集」で品物ごとに「単価」を入力して保存します。
6. 終わったら「ロック」を押すか、「在庫操作に戻る」を押します。

## よくある困りごととその場の対処

- 「金額」が「—」のときは、単価がまだ入っていません。「単価を入れる」から入力します。
- 「確認するものはありません」と出たら、まとめる候補はありません。
- 「パスワードが違います」と出たら、正しい4桁を入力し直します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
