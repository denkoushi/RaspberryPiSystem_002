# 製品構成・正式ID

## この画面でできること

完成品に組み込む子アセンブリを紐付け、構成を確認できます。
完了した最上位の完成品へ正式IDを付け、訂正の履歴を残せます。

## 基本の手順

1. 管理パスワードの入力画面でパスワードを入力します。
2. 「完成品の作業用ID」の入力欄を押し、バーコードを読み取ります。手入力なら入力後に「確認」を押します。一覧の候補を押して選ぶこともできます。
3. 子を追加する場合は「完了済み子の作業用ID」の欄を押して読み取り、または入力し、「紐付け」を押します。
4. 「正式ID」の欄を押して読み取り、または入力し、「付与」を押します。
5. 「構成ツリー」と正式IDの履歴を確認します。
6. 変更するときは対象の「親変更」「解除」「訂正」を押し、「理由」を入力して「確定する」を押します。親変更では「変更先 親作業用ID」も入力します。正式IDの訂正は、先に正式ID欄を新しい番号へ直します。
7. 「組立状況へ戻る」で戻ります。

## よくある困りごととその場の対処

- 「パスワードが違います。」：「認証する」から入力し直します。
- 「親（完成品）の作業用IDを入力してください。」：完成品の入力欄に作業用IDを入れ、「確認」を押します。
- バーコードが別の欄に入る：先に入力したい欄を押してから読み取ります。
- 子を紐付けできない：完了済みで、別の親に紐付いていない子のIDか確認します。
- 「付与」が押せない：正式IDの入力と、対象の最上位完成品が完了済みかを確認します。過去に使った正式IDも再利用できません。
- 「理由を入力」や「変更先を入力」：表示された不足項目を入力します。取りやめる場合は「キャンセル」を押します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
