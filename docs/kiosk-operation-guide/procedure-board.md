# 手順づくり

## この画面でできること

案件を選び、素材(写真やメモ)をページに置いて手順書の形に並べます。
置いた素材は動かす、横に並べる、幅を変える、外す、文章を直すことができます。
AI が置き場所の提案を黄色の地と点線で重ねて表示するので、使うものだけ置きます。
置いた内容は自動で保存されます。
盤面は暗い配色です。左の素材は日付と種類を添えたカード、右のページは用紙で表示します。最初は3ページで、1〜20ページに増減できます。3枚分の幅を基本に横へスクロールします。
文字はゴシック体で、タイトルとサブタイトルには細い下線が付きます。1ページ目にサブタイトルの目次が出て、押すとその見出しへ移ります。
選んだ項目は青い輪郭、抜けは黄色、食い違いは赤で表示します。食い違いの選択肢には、分かる場合だけ素材の日付と種類が付きます。

## 基本の手順

1. ポータルで「手順づくり」を押し、案件を選びます。
2. 左の「素材」から写真やメモを押さえたまま、右のページへ動かして置きます。青い差し込み線が出た場所に置かれます。
3. 置いた素材を別の場所や別のページへ動かします。素材の横に置くと横に並びます(1行に3つまで)。境目を動かすと幅が変わります。
4. 文章は押すと直せます。Enter で確定し、Esc で取り消します。
5. 各ページの番号の右にある記号ボタンで「タイトル」「サブタイトル」「本文」を足せます。マウスを乗せて少し待つとボタン名が出ます。そのページの札を選んでいれば直後に入り、選んでいなければタイトルは先頭、ほかは末尾に入ります。「複製」は同じページの札を選んでいるときに使えます。要らないものは選んで「×」を押すか、Delete キーを押します。
6. 点線で出ている AI の提案は、「✓」で置き、「×」で消します。提案を押さえたまま別の場所へ動かして置くこともできます。見出しの提案も「✓」で使い、「×」で消します。見出しの提案も押さえたまま動かせます。使った見出しは、ほかの文字と同じように動かし、直し、消せます。
7. 全体を並べ直すときは「AIで整える」を押します。整え終わると結果が重なって表示されるので、よければ「採用」、やめるときは「戻す」を押します。整えている間も他の操作はできます。

タッチ画面では、素材を少し長く押してから動かします。すぐに指を動かすと一覧がスクロールします。

## ページを増やす・並べ替える・消す

- 見出し帯には「ページ番号 / 総ページ数」が出ます。「＋」でそのページのすぐ右に空ページを足します。20ページになると追加できません。
- 見出し帯のボタン以外を押さえて横に動かすと、青い縦線の位置へページごと移せます。端に寄せると横スクロールし、Esc で取り消せます。タッチでは250ms長押ししてから動かします。
- ゴミ箱を押すと「ページNを削除しますか?」が出ます。「削除」でそのページと中の札を消します。「やめる」、Esc、外側を押す操作で取り消します。1ページだけのときは削除できません。
- 「−」でページや素材を折りたたみ、「＋」で開きます。ページを並べ替えても、折りたたみ状態は同じページに付いて移ります。
- ページ構成を変えると、以前のAI提案は消えます。現在の盤面で作り直した提案が届くと表示されます。

## よくある困りごととその場の対処

- 「手順づくりは無効です」：この端末では使えません。使う端末かどうかを管理者に確認します。
- 「保存できませんでした。下書きは保持しています。」：通信が戻ると自動で保存し直します。そのまま作業を続けて構いません。
- 「盤面が更新されています。下書きは保持しています。」：別の端末で同じ案件が変わりました。上の「↻」を押して最新を取り、もう一度「↻」を押すと、保存していない操作を最新の盤面に載せ直して続けられます。前の内容は「▤」で見られます。
- 「この場所には置けません」：1行に4つ以上は並べられません。別の行かページに置きます。
- 「素材がありません」：この案件にはまだ写真やメモがありません。
- 点線の提案が出ない：素材を動かしている間や文章を直している間は、新しい提案を表示しません。操作を終えると表示されます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
