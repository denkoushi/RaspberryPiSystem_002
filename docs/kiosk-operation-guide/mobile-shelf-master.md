# 棚マスタ — 工場全体

## この画面でできること

工場全体の区画と、加工機・部品置き場の配置を確認します。
「再割当」では、移動元と移動先の部品置き場を選べます。
「レイアウト」が表示される端末では、区画の用途を編集できます。

## 基本の手順

再割当をするときの手順です。

1. 配膳の画面で「棚マスタ」を押します。
2. 「再割当」を押し、操作したい区画の図を押します。
3. 「移動元の部品置き場をタップ」の案内に従って、移動元の棚を押します。
4. 移動元の表示を確かめてから、移動先の棚を押します。この操作で再割当が実行されます。
5. 「再割当が完了しました」と表示されたことを確認します。

区画の用途を変えるときは、次の手順です。

1. 「レイアウト」を押し、対象の区画の「編集」を押します。
2. 変更するマスを選び、「部品置き場」「加工機」「通路」「未使用」から用途を選びます。
3. 「加工機」を選んだ場合は、加工機の一覧から対象を選びます。
4. 「確定」を押して用途を割り当てます。ほかにも変更があれば、マスの選択から繰り返します。
5. マスの選択がない状態で、もう一度「確定」を押してレイアウトを保存します。

## よくある困りごととその場の対処

- 「レイアウト」が見えないときは、その端末ではレイアウト編集が有効になっていません。「再割当」で配置を確認できます。
- 再割当でマスを押せないときは、棚のマスを選んでください。移動先には移動元と違う棚を選びます。「処理中…」の間は待ってください。
- 用途を選べないときは、先に変更するマスを選んでください。
- 「確定」を押せないときは、用途を選んだか確認してください。「加工機」では対象の加工機も選ぶ必要があります。
- 「未保存の変更があります。閉じて破棄しますか？」と出たら、変更を残したい場合は閉じる操作を取り消し、保存の手順を終えてください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
