# パレット可視化

## この画面でできること

加工機のパレットごとに、登録された部品を確認できます。
バーコードを読んで部品を追加・上書きし、登録を削除できます。

## 基本の手順

1. 左側の加工機を選び、パレット番号を押します。
2. 新しく追加するときは、部品が選択されていないことを確認します。選択中の部品をもう一度押すと選択を外せます。
3. 「追加」を押し、コードをカメラに向けます。読み取ると登録され、一覧が更新されます。
4. 置き換えるときは対象の部品を選び、「上書」を押して新しいコードを読みます。
5. 1件を消すときは部品を確認して「選択削除」を押します。選択したパレットの全部品を消すときは、パレット番号を確認して「全削除」を押します。

部品を選択したまま「追加」を押した場合も、その部品が上書きされます。
削除の確認画面は出ないため、押す前に対象を確かめてください。

## よくある困りごととその場の対処

- 「上書」「選択削除」を押せないときは、対象の部品を選びます。処理中は終わるまで待ちます。
- 「このパレットに部品はありません」と出たら、加工機とパレット番号を確認します。新しい部品の登録は「追加」で行います。
- 「イラスト未設定」の場合は、機械名と番号で対象を確認します。
- 「読み込みに失敗しました」「加工機データを読み込めませんでした」と出たら、少し待って自動更新後の表示を確認します。
- カメラで読み取れないまま画面が閉じたときは、対象と選択状態を確認してから、追加または上書きをやり直します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
