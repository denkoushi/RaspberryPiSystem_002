# 吊具 持出

## この画面でできること

吊具の情報と点検見本を確認し、社員証で持出を登録します。
吊具のタグ、社員証の順にかざします。

## 基本の手順

1. 吊具のタグをかざします。
2. 「名称」「管理番号」「保管場所」「荷重(t)」を見て、対象を確認します。
3. 「点検見本（確認のみ）」の画像を参照し、現物を目で点検します。
4. 社員証をかざすと、自動で持出登録が進みます。
5. 登録が終わると、端末の設定に応じた持出画面へ戻ります。

## よくある困りごととその場の対処

- 「吊具タグをスキャンしてください」と出たら、社員証より先に吊具のタグをかざします。
- 「吊具情報を取得中…」の間は、情報が表示されるまで待ちます。
- 「タグ未登録（吊具）」と出たら、対象のタグか確認します。登録の確認はお問い合わせへ送ってください。
- 間違ったタグを読んだときや、持出に失敗したときは「リセット」を押して最初からやり直します。
- 「送信中…」の間は、登録が終わるまで待ちます。
- 一覧へ戻りたいときは「持出一覧へ戻る」を押します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
