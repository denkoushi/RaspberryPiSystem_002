# 照合（移動票・現品票）

## この画面でできること

製造番号のバーコードを読み取り、置く棚と配分を登録します。
登録済みの配分を別の棚へ移すこともできます。
移動票と現品票の内容を入力して照合できます。

## 基本の手順

1. 棚を置くエリアと列を両方押し、表示された棚番を選びます。棚の読み取りマークから棚のQRコードを読むこともできます。
2. 下側の「製造order番号」の横にある読み取りマークを押し、製造番号のバーコードを読み取ります。
3. 新しく配分を作る場合は「新規配分」を押します。棚を移す場合は「既存配分」を押し、移動する分配を一覧から選びます。
4. 選んだ棚と分配を確かめて「確定」を押し、登録または移動の結果を確認します。
5. 票を照合する場合は、上側の「展開」を押します。移動票と現品票の各欄に番号を入力するか、読み取りマークから読み取ります。
   現品票は「注文番号（バーコード）」から注文番号を読み取ります。同じ欄に製造orderも入力できます。バーコードが読めない場合は「画像OCR」や製番の手入力を使い、両票の部品番号も入力してください。
6. 「照合」を押し、「OK」または「NG」を確認します。「閉じる」で照合欄を折りたためます。

## よくある困りごととその場の対処

- 棚の一覧が出ないときは、エリアと列を両方選んでください。
- 「この組み合わせの登録棚はありません」と出たら、選んだエリアと列を確認してください。
- 「登録済み棚の取得に失敗しました」または「分配一覧の取得に失敗しました」と出たら、その近くの「再試行」を押してください。
- 「確定」を押せないときは、棚と製造番号がそろっているか確認してください。「既存配分」では移動する分配の選択も必要です。処理中は完了を待ってください。
- 既存の分配がない案内が出たら、先に「新規配分」で登録してください。
- 「NG」と出たら、両方の票と入力内容を確認し、必要な欄を直してもう一度「照合」を押してください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
