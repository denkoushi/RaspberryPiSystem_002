# 集計

## この画面でできること

吊具・工具などのアイテム・計測機器の持出と返却を集計して見られます。
貸出中や期限超過、未返却、社員別の件数、今日の履歴を確認できます。

## 基本の手順

1. 「吊具」「アイテム」「計測機器」から調べる種類を選びます。
2. 年月が出ている部分を押し、「対象期間」で年月を選びます。日ごとに見るときは「1日」を選んで日を指定します。
3. 品物の選択欄で対象を絞ります。絞り込みを外すときは「すべて」を選びます。
4. 「上位10」「全件」で一覧の表示を切り替えます。
5. 「貸出中」「期限超過」や「未返却」の一覧を確認します。

## よくある困りごととその場の対処

- 「データを取得できませんでした。」と出たら「再試行」を押します。
- 「データがありません。」と出たら、期間・品物の種類・品物の絞り込みを確認します。
- 「未返却なし」は、表示する未返却がない状態です。
- 「今日はまだありません」は、今日の履歴がない状態です。
- 最新の期間では右向き矢印を押せません。過去を調べるときは左向き矢印や年月の選択を使います。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
