# タグ管理

## この画面でできること

タグをかざして、誰・何についたタグかを確認できます。
社員・工具・計測機器・吊具にタグを付けたり、外したりできます。
登録情報の追加・編集もできます。

## 基本の手順

1. 数字ボタンで4桁のパスワードを入力します。4桁そろうと自動で確認されます。
2. タグをかざし、「紐づけ先」を確認します。
3. 「未使用のタグ」を付ける場合は、右側で「社員」「工具」「計測機器」「吊具」を選び、付ける相手を選びます。「名前・コード」で検索できます。
4. 相手の名前が書かれた、タグを付けるためのボタンを押します。
5. 外す場合は対象の「外す」を押し、確認内容を読んで、もう一度「外す」を押します。中止は「やめる」です。

社員・工具にすでにタグがある場合は付け替えになります。計測機器・吊具にはタグを追加できます。
画面を離れるとロックされ、次に開いたときはパスワードが必要です。

## よくある困りごととその場の対処

- 「パスワードが違います」と出たら、正しい4桁を入力し直します。
- 「確認できませんでした。通信を確認してください」と出たら、通信状態を確認します。
- 相手が見つからないときは種類と検索語を見直します。「タグなし」で絞っている場合は、もう一度押して解除します。
- 「貸出中です。外すとかざして返却できません」と出たら、「やめる」で中止できます。
- 在庫の棚・数量タグを付けたいときは「在庫の準備」を使います。
- 「付けられませんでした」「外せませんでした」が続く場合は、対象と表示内容をお問い合わせへ送ってください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
