# 検査記録確認

## この画面でできること

自主検査の測定値、入力した人、点検状況を確認します。
条件がそろった記録を、承認者の社員証を使って承認できます。
完了した記録や、削除された記録の履歴も確認できます。

## 基本の手順

1. 「未完了」「完了記録」「削除履歴」から、見たい一覧を選びます。
2. 必要に応じて「製造order」「資源CD」で絞り、左の一覧から対象を選びます。
3. 測定値と「作業点検」「検査点検」を確認します。入力の不足は「作業者入力へ」、再測定の案内がある場合は「検査員測定へ」などから確認します。
4. 承認できる記録では「承認を開始」を押します。その後、承認者の社員証をかざします。
5. 読み取った承認者名を確認し、「承認して完了」を押します。やめる場合は「キャンセル」を押します。
6. 「検査記録を承認し、自主検査を完了しました。」の表示を確認します。

検査員が最終判定する記録は、表示される「最終判定へ」「最終確定へ」から検査員の画面へ進みます。

## よくある困りごととその場の対処

- 「左の一覧から検査記録を選択してください。」と出たら、まず対象を選びます。
- 「入力と使用前点検がそろうと承認できます。」と出たら、不足する入力や点検を確認し、対応する入力画面へ進みます。
- 「検査員再測定がそろうと承認できます。」と出たら、検査員の再測定をそろえます。
- 社員証をかざしても承認者が出ない場合は、先に「承認を開始」を押します。
- 「計測機器タグでは承認できません。社員タグをタッチしてください。」と出たら、承認者の社員証をかざします。
- 「削除済み・閲覧専用」の記録は、この画面で編集や承認はできません。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
