# テンプレート

## この画面でできること

組立に使う文書、表示する順番、工程、丸数字やチェックの位置を設定できます。
新しく作る場合は保存し、既存の設定を直す場合は新しい版として保存できます。

## 基本の手順

1. パスワード入力画面が出たら「パスワード」を入力して「認証」を押します。
2. 「テンプレート名」を確認します。「文書」タブで機種名と手順パターン、使用する文書を確認します。必要な文書は「文書追加」から選びます。
3. 「工程」タブで対象工程とページを選びます。工程を増やす場合は「＋ 工程」を押します。
4. 右側の「締結」または「チェック」を選び、ページ上に丸数字やチェックを置きます。選んだ箇所の条件や、チェックのラベルを設定します。
5. ページ全体を手順に使う場合は「全体追加」を押します。「手順」タブで表示順を確認し、「前へ」「次へ」で並べ替えます。
6. 保存条件を満たしたら、新規は「保存」、編集は「新しい版で保存」を押します。保存後はテンプレート一覧へ戻ります。

## よくある困りごととその場の対処

- 「パスワードが違います。」：入力を直して「認証」を押します。
- 「表示のみ」：無効になった版は編集できません。新しく作る場合は「複製して新規」へ進めます。
- 保存ボタンが押せない：画面の作成ガイドで未完了の項目を確認し、その項目を押して直します。
- 「表示手順を1件以上追加してください。」：ページを選び、「全体追加」などで表示する手順を追加します。
- 「未使用文書あり」：追加した文書を表示手順に使うか、不要なら文書一覧から外します。
- 「改版では固定」：既存の版では機種名と手順パターンを変えられません。別の設定を作る場合は「複製して新規」を使います。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
