# 部品測定

## この画面でできること

移動票から測定する部品を探し、記録表に測定値を入れます。
途中の記録を開き直したり、確定した記録を検索したりできます。
測定に使うひな形がない場合は、テンプレートを作成できます。

## 基本の手順

1. 工程の「切削」または「研削」を選びます。
2. 「製造order番号」に移動票の番号を入れます。「バーコード」から読み取ることもできます。
3. 「日程を照会」を押します。「候補を選択」が出たら、製番・品番・資源を確認して対象を選びます。
4. テンプレートの選択画面が出たら、対象の「このテンプレで続ける」を押します。
5. 表形式の記録表では「個数」を入れ、各部品の測定値を入力します。社員証をかざし、表示された作業者名を確認します。
6. 途中で保存する場合は「手動保存」を押します。入力を終えたら「確定」を押します。
7. 確定した記録は「確定記録の閲覧」で条件を入れ、「検索」、対象の「開く」の順に押します。

テンプレートを新しく作る場合の手順です。

1. 選択画面で「新規テンプレを作成」を押します。
2. 「テンプレート名」を入れ、「基準面」「測定部位」「測定項目名」を少なくとも1行そろえます。項目を増やすときは「行を追加」を押します。
3. 必要なら「図面テンプレート（任意）」で図面を選び、「登録して有効化」を押します。
4. 元の画面に戻ったら、もう一度「日程を照会」から記録表を開始します。

## よくある困りごととその場の対処

- 「日程データに該当する製造order番号がありません。」と出たら、移動票の番号と資源の絞り込みを確認して照会し直します。
- 「候補がありません。新規テンプレを作成してください。」と出たら、絞り込みを見直すか「新規テンプレを作成」へ進みます。
- 「個数を入力すると入力欄が表示されます。」と出たら、先に「個数」を入れます。
- 「別端末が編集中」と出たら、別の端末での作業を確認します。この端末で続きを行う場合は「引き継ぐ」、行わない場合は「閉じる」を押します。
- 「測定値入力中の記録はありません。」と出たら、「測定値入力中を更新」で確認します。新しく始める場合は移動票から照会します。
- 「測定項目を1行以上入力してください。」と出たら、同じ行の「基準面」「測定部位」「測定項目名」をそろえます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
