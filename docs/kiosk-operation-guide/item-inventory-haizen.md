# 配膳の場所

## この画面でできること

配膳スマホで棚に置いた部品が、どの棚にあるかを棚の写真から確かめられます。
機種名・品番・製番で、部品が置いてある棚を探せます。

## 基本の手順

1. 「在庫操作」の上部にある「配膳の場所」を押します。
2. 棚の写真が並びます。写真の上の数字は、その棚に置いてある部品の件数です。何も無い棚は暗く「空き」と出ます。
3. 棚を押すと、その棚の部品が新しく置いた順に出ます。「前の棚」「次の棚」で隣の棚へ、「棚の一覧へ」で写真の一覧に戻ります。
4. 番号で探すときは「番号で探す」を押し、上で「機種名」「品番」「製番」を選んで、キーで入力して「探す」を押します。下に出る候補を押しても探せます。
5. 声で探すときは「声で探す」を押し、「製番 BA1S2320」のように種類と番号を話してから、もう一度押して止めます。
6. 見つかった棚だけが残り、合った部品は水色で示されます。棚が1つだけなら、その棚の中身がすぐ開きます。「やめる」で全部の棚に戻ります。
7. 「‹ 在庫へ」で在庫の画面に戻ります。

## よくある困りごととその場の対処

- 「一致する部品はどの棚にもありません」と出たら、番号の一部だけを入れて探し直します。
- 声で探せないときは、「番号で探す」を使います。
- 置いたはずの部品が出ないときは、配膳スマホで登録できているか確かめます。画面は1分ごとに新しくなります。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
