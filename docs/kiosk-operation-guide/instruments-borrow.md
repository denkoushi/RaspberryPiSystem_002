# 計測機器 持出

## この画面でできること

計測機器を選び、点検項目や見本の画像を確認して持出を登録します。
機器のタグをかざす方法と、一覧から選ぶ方法があります。

## 基本の手順

1. 計測機器のタグをかざすか、「計測機器を選択」で対象を選びます。
2. 「点検項目」と画像を確認して、機器を点検します。
3. 社員証をかざします。読み取ると自動で持出登録が進みます。
4. 登録が終わると、端末の設定に応じた持出画面へ戻ります。
5. 返すときは、戻った画面の「持出一覧」で対象を確認して「返却」を押します。

## よくある困りごととその場の対処

- 「計測機器を選択すると点検項目が表示されます。」と出たら、先に対象の機器を選びます。
- 「点検項目を読み込み中…」の間は、点検内容が出るまで待ちます。
- 「送信に失敗しました。再スキャンしてください。」と出たら、社員証をもう一度かざします。
- 「既に貸出中です」と出たら、持出一覧で対象の機器を確認します。
- 「計測機器タグの取得に失敗しました。氏名タグをスキャンして続行できます。」と出た場合は、選んだ機器を確認して社員証をかざします。
- 「タグ未登録（社員）」が出た場合や、機器のジャンル・画像が未設定で持出できない場合は、表示内容をお問い合わせへ送ってください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
