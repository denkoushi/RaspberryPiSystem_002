# 記録確認

## この画面でできること

完了した製品の締付けとチェックの実績を確認できます。
社員タグで承認者を確認して、記録を承認できます。

## 基本の手順

1. 「記録確認の暗証番号」で番号を入力します。入力後も画面が閉じない場合は「OK」を押します。
2. 「未承認」「承認済み」「全て」で対象を選びます。「製番・作業者」に入力して絞り込めます。
3. 一覧で対象の製品を押し、製番、機種、作業者を確認します。
4. 「エリア別トルク実績」と「チェック実績」を確認します。
5. 「承認: タグをかざす」が出ているときに、承認する人の社員タグをかざします。
6. 表示された承認者の名前を確認し、その名前が入った承認ボタンを押します。「承認済み」の一覧で結果を確認できます。
7. 「組立へ戻る」で戻ります。

## よくある困りごととその場の対処

- 暗証番号の入力を閉じてしまった：「再認証」を押します。
- 「違います」：入力した暗証番号を訂正します。「少し待ってください」の場合は、少し待ってからやり直します。
- 「該当する完了製品がありません」：検索語を消し、「全て」で確認します。
- 「一覧の取得に失敗しました。」：丸い矢印ボタンで読み込み直します。
- 「未登録のNFCタグです。」：使用したタグを確認し、登録済みの社員タグをかざします。
- 承認ボタンが押せない：社員タグの照合と名前の表示を待ちます。別の製品を選んだ後は、もう一度タグをかざしてください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
