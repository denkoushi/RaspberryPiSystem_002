# 順位ボード

## この画面でできること

資源ごとに作業の一覧を見て、進める順位を設定できます。
製番や、完了・未完の状態で表示を絞り込めます。
作業の納期や備考も確認できます。

## 基本の手順

1. 左側の操作欄で「工場」と「対象端末」を選びます。操作欄が隠れている場合は、マウスの矢印を画面の左端に合わせます。
2. 資源スロットのボタンを押します。「順位ボードの資源スロット」で「スロット数」を選び、各欄で資源を選んで「閉じる」を押します。
3. 「研削」「切削」を切り替え、見たい作業を表示します。
4. 「表示」の「両方」「未完」「完了」で、表示する作業の状態を選びます。
5. 各行の順位の数字、または「-」を押して、候補から順位を選びます。選んだ順位が保存されます。「-」を選ぶと順位の指定を外せます。

## よくある困りごととその場の対処

- 一覧が出ず、端末や資源の設定を促す文が出るときは、「対象端末」を選び、資源スロットに1件以上の資源を割り当てます。「研削」「切削」の選択も確認します。
- 見たい製番がないときは、「製番OR検索を全解除」で製番の絞り込みを外します。完了した作業も見る場合は「両方」を押します。
- 完了した行は順位を変更できません。未完の作業を選んでください。保存処理中に押せない場合は、終わるまで待ちます。
- 順位一覧の追加読み込みに失敗し、一部しか表示されない可能性があると案内されたときは、少し待ってから画面を再読み込みしてください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
