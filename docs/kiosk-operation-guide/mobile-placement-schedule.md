# 配膳の日程

## この画面でできること

週ごとに届くエクセル日程の製番を、部品完成日の近い順に一覧で見られます。
製番を押すと、その製番の部品が「棚にある」「照合済み」「まだ」「完了」に分かれて表示されます。
「棚にある」では、部品が置いてある棚が写真付きで表示されます。
この画面から照合を始め、照合した部品を棚に置くところまで進められます。

## 基本の手順

1. 配膳の画面で右上の「⋮」を押し、「ほかの画面」の中の「日程」を押します。
2. 一覧の上の「すべて」か「揃っていない」を押して、表示する製番を切り替えます。
3. 見たい製番を押すと、その製番の画面に移ります。
4. 上の「棚にある」「照合済み」「まだ」「完了」を押して、見たい部品の状態に切り替えます。
5. 「棚にある」では棚のカードを押すと、その棚の写真と中身がすべて表示されます。
6. 「照合済み」や「まだ」の部品を押すと、その部品を狙いにして照合が始まります。下の「照合」を押すと、部品を選ばずにこの製番の照合を始められます。
7. 照合のあと、置く棚を選んで「ここに置く」を押します。部品は「棚にある」の側に移ります。
8. 左上の戻るボタンで、製番の一覧や配膳の画面へ戻れます。

## よくある困りごととその場の対処

- 「日程はありません」と出たら、エクセル日程がまだ取り込まれていないか、未完の部品がある製番がありません。
- 「日程を取得できません」と出たら、通信状態を確認して画面を開き直してください。
- 「部品はありません」と出たら、その状態の部品はありません。上で別の状態に切り替えてください。
- 照合で「別の部品」や「別の製番」と出たら、読んだ票が狙いの部品ではありません。票を確かめてください。
- 「200件まで表示」と出たら、製番が多いため先頭の200件だけを表示しています。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
