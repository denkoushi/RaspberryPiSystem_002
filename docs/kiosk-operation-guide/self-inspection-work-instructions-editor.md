# 加工要領書

## この画面でできること

加工要領書に文字・図形・画像を追加し、手順ごとの作業メモを編集できます。
下書きを保存し、内容を確認して公開できます。操作の履歴や原本との比較も確認できます。

## 基本の手順

1. 自主検査から対象の要領書を開き、「編集」を押します。
2. 「社員タグ」と表示されたら、編集する人の社員証をかざします。
3. 左側の手順を選びます。複数の原本がある場合は、上部で対象の原本を切り替えます。
4. 右側の文字・図形のボタンで書き足し、選んだ内容を編集します。範囲を選ぶボタンからは、図面上をなぞって追加する範囲を選べます。
5. 作業メモは右側のその他のボタンから「メモ」を開いて編集します。
6. 右側の保存ボタンを押し、「保存済み」になったことを確認します。
7. 公開する場合は右側の公開ボタンを押し、確認画面の下書き件数と要確認件数を確認して「公開する」を押します。

その他のメニューの「比較」で原本との違いを、「履歴」で操作や版を確認できます。

## よくある困りごととその場の対処

- 「品番と対象が指定されていません。」と出たら、「戻る」で自主検査へ戻り、対象の要領書を開き直します。
- 「認証の期限が切れました。社員タグをかざしてください。」と出たら、もう一度自分の社員証をかざします。
- 保存ボタンが押せない場合は、変更の有無と追加した内容を確認します。画像の未選択や文章の未入力があれば、そろえてから保存します。
- 「未保存」と出ている間は、保存ボタンを押して保存結果を確認します。
- 「別の社員が更新しました。未保存内容を保持しています。」と出たら、他の人の変更を確認します。自分の入力を残して保存する場合は「保持内容を再保存」を押します。
- 最新の内容に置き換える場合は「最新を再読込」を押し、確認画面を読みます。「最新内容へ置換」を押すと、現在の未保存内容は破棄されます。
- 要確認のメモで公開できない場合は、要確認の表示から対象を開き、メモを確認してから保存・公開し直します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
