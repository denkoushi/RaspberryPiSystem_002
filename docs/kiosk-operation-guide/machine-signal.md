# 設備稼働

## この画面でできること

日報をもとに、全体や機械ごとの稼働・停止を確認できます。
日付や期間を変えたり、よく見る機械をピン留めしたりできます。

## 基本の手順

1. 「全体」で設備全体の状態を見ます。
2. 日付表示を押し、「1日」か「期間」を選びます。期間は「始まりの日を選ぶ」、次に「終わりの日を選ぶ」に従って選びます。
3. まとめて見る場合は「直近7日」「直近30日」「今月」「先月」も使えます。
4. 「機械別」を押し、一覧から機械を選びます。全体画面の機械名を押しても移れます。
5. よく見る機械はピンの印を押して登録し、「ピン留め」で絞り込みます。印をもう一度押すと解除できます。
6. 過去の日付から最新へ戻るときは「最新」を押します。

## よくある困りごととその場の対処

- 「ピン留めした機械がありません」と出たら「すべて」に戻り、見たい機械のピンの印を押します。
- 日付を押せないときは、日報がある選択可能な日を選びます。
- 期間表示中は左右の日送り矢印を使えません。「1日」で日を選びます。前後に表示できる日報がない場合も、矢印は押せません。
- 「日報がまだありません」と出る場合は、表示する日報がありません。
- 「読み込めませんでした」が続く場合は、見ていた日付や機械名を添えてお問い合わせへ送ってください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
