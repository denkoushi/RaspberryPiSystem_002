# テンプレート

## この画面でできること

この入口を開くと、組立の「テンプレート」一覧へ自動で移動します。
機種名が指定された入口から開いた場合は、その機種名で絞り込まれます。
対象の設定を探し、編集画面へ進めます。

## 基本の手順

1. 移動先で「テンプレート」が選ばれていることを確認します。
2. 「機種名」や「全体検索」で対象を探します。
3. 有効な対象の「改版」を押し、編集画面へ進みます。
4. 文書や手順の順番は、移動先のテンプレート編集画面で確認します。

## よくある困りごととその場の対処

- 設定画面ではなく一覧が開いた：この入口はテンプレート一覧へ移動します。対象の「改版」から進んでください。
- 「条件に合う組立テンプレートはありません。」：機種名や検索語を確認します。×ボタンで検索条件を解除できます。
- 無効なものも探したい：「無効化済みも表示」を選びます。無効な版は「表示」から内容を確認できます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
