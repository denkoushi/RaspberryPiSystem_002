# 締付トルク訓練

## この画面でできること

社員タグで作業者を確認し、訓練メニューを選んで結果を記録できます。
訓練中の記録と、終了後の結果を確認できます。

## 基本の手順

1. 「タグをかざす」の表示が出ているときに、自分の社員タグをかざします。
2. 表示された名前を確認し、「メニュー」で対象を選びます。
3. 「訓練を開始」を押します。
4. 「接続前のレンチ設定」または「接続前のレンチ確認」の案内と製造番号を確認します。案内に従って確認したら「レンチ本体を表示値に設定して接続」を押します。
5. 接続待ちの表示が消え、締付けの本数が表示されたことを確認します。訓練の記録は画面の枠に表示されます。
6. 終了後に結果を確認し、「訓練完了」を押して最初に戻ります。

## よくある困りごととその場の対処

- メニューを選べない：先に社員タグをかざし、名前を確認します。「使用不可」のメニューは選べません。
- 「訓練メニューがありません」：選べる訓練がありません。「組立へ戻る」で戻れます。
- 「NFCタグを確認できませんでした。」：確認処理が終わってから、社員タグをかざし直します。
- 作業者を替えたい：「別の作業者」を押してから次の人のタグをかざします。進行中の訓練は終了します。
- 「Bluetooth接続待ち」：画面の「青ランプ点灯まで締付けない」に従い、接続を待ちます。
- 「確認済み・接続を再試行」：接続ボタンをもう一度押します。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
