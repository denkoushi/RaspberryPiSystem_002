# お問い合わせ

## お問い合わせを送る

送るときに社員証は不要です。受信担当の端末でも、鍵を開けずに新規送信できます。

1. 画面右下の丸いボタンを押し、「お問い合わせ」から「＋ 新規」を押します。すでに「新規」の入力画面なら、そのまま進みます。
2. 「部署」を選び、「送信者」で自分の名前を押します。部署が見えない場合は「⋯」を押します。
3. 「依頼」に用件を200文字以内で書きます。最初は「現場まで来てください。」が入っています。
4. 補足があれば「日時・詳細」を開き、「詳細」に端末名、行った操作、画面に出た内容を書きます。
5. 打合せ日時も送る場合は「打合せ日」と「打合せ時刻」を確認します。日時は、この欄を開いたまま両方に値があると送られます。
6. 「送信」を押します。通常の送信端末では送った内容が開きます。鍵がかかった受信端末では「送信しました」と出て鍵の画面に戻ります。

名前を選び直すときは、選択中の名前をもう一度押します。
「依頼」の横にある時計のボタンから、この端末で送った過去の依頼を選べます。

## 返事を読む・追記する

1. 返信が届くと、丸いボタンがオレンジ色になり件数が出ます。ボタンを押して「お問い合わせ」を開きます。
2. 一覧から読みたいものを押します。通常の送信端末では、その端末から送った分を社員証なしで読めます。
3. 「返信」に追記を書き、右の矢印ボタンで送ります。500文字まで入力できます。

「了解です」「お願いします」は、押すとそのまま相手へ送られます。
受信担当の端末で「社員証をタッチ」が出た場合は、受信箱を開ける人として登録された自分の社員証をかざします。

## 送れない・見つからないとき

- 「送信」が押せない場合は、自分の名前が選ばれ、「依頼」が空欄でないことを確認します。
- 「送信中…」や「読込中…」の間は待ちます。
- 「少し待ってから送ってください」が出たら、待ってから「送信」を押します。
- 「送信できません」が出ても入力は残ります。内容を確認して、もう一度送れます。
- 「お問い合わせはありません」と出た場合は一覧が空です。返事を探すときは、送った端末を確認してください。
- 受信箱が「この社員証では開けません」でも、新しい用件は「＋ 新規」から送れます。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
お問い合わせ自体を送れない場合は、担当者に直接伝えてください。
