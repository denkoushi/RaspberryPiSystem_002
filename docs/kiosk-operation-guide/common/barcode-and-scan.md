# バーコードと写真の読み取り

## スキャナーで読む

1. 自主検査では、読みたいものに合わせて「移動票スキャン」か「部品番号スキャン」を押します。
2. 読み取りを待つ案内が出たら、移動票の該当するバーコードをスキャナーで読みます。
3. 画面に入った番号を確認します。やめるときは「スキャン中止」を押します。

製造order番号は数字10桁です。読み直す案内が出たら、もう一度スキャンのボタンを押して読みます。

## カメラでバーコード・QRを読む

1. 「スキャン」や「バーコード」がある画面では、そのボタンを押します。配膳で棚を選ぶときは「QR」を押します。
2. 「コードをカメラに向けてください」が出たら、対象のコードをカメラに向けます。
3. 読み取り後に入った番号や棚を確認します。途中でやめるときは「キャンセル」を押します。

棚の「QR」はQRコードに対応しています。要領書検索のカメラ読み取りでは、縦線が並ぶバーコードを使います。

## 在庫の写真から文字を入れる

写真読み取りは、写真に写った名前や型式などの文字を入力するために使います。

1. 在庫の登録画面で、取り込まれた写真を押して大きく表示します。
2. 「文字を枠で囲む」が出たら、読みたい文字を指やマウスで囲みます。
3. 出てきた候補を選び、「名前」「型式」など、入れたい欄の「入れる」を押します。
4. 入った文字を確認します。違う文字は欄を押して直し、「閉じる」で戻ります。

## 読めないとき

- 「カメラを使えません」が出たら「閉じる」で戻ります。手入力できる欄があれば、番号を入力します。
- 「文字なし。囲み直す」が出たら、写真の文字を囲み直します。
- 「読み取れませんでした」が出たら、囲み直すか、写真の切り替えボタンで別の写真を選びます。
- 「読み取り中…」の間は、終わるまで待ちます。候補がないと「入れる」は押せません。
- 読み取り直しても進めない場合は、どのコードや写真を使ったかを添えて連絡してください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
