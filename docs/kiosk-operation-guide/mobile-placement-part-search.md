# 部品名で棚を探す

## この画面でできること

部品名や部品番号で、登録されている部品の置き棚を探します。
機種名も入れると、候補を絞り込めます。
候補には棚番や製造番号、製番などが表示されます。

## 基本の手順

1. 配膳の画面から「部品名で棚を探す」を押します。
2. 上側の入力欄に部品名や部品番号を入れます。画面の文字ボタンでも入力できます。
3. 必要なら下側の入力欄に機種名を入れます。文字ボタンは最後に選んだ入力欄に入ります。
4. 表示された候補の部品名と棚番を確認します。候補を押すと、一覧の下にもその内容が表示されます。
5. 入力を直すときは直したい欄を選び、「削除」で末尾を1文字ずつ消します。「戻る」で配膳の画面へ戻れます。

## よくある困りごととその場の対処

- 「該当なし」と出たら、部品名の入力を確かめてください。機種名を入れている場合は、その内容も確認して絞り込みを見直してください。
- 「検索中…」と出ている間は、候補が表示されるまで待ってください。
- 「検索に失敗しました。通信を確認してください。」と出たら、通信状態を確認してください。
- 文字が違う欄に入るときは、入力したい欄を押してから文字ボタンを押してください。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
