# 足取り

## この画面でできること

製造オーダーの番号から、その品物が通った工程、置かれた棚、照合、パレット、購買の記録を、新しい順に見られます。
いまどの棚にあるかも分かります。

## 基本の手順

1. 「在庫操作」の「配膳の場所」で「足取り」を押します。棚の中身や照合の記録の「足取り」からも開けます。
2. キーで製造オーダーの番号を入れます。「⌫」で1字、「C」で全部消せます。
3. 上に品名・製番・品番・機種名と、いま置いてある棚が出ます。棚を押すと、配膳の場所でその棚が開きます。
4. 工程の札を押すと、その工程の記録だけになります。もう一度押すと全部に戻ります。
5. 「全部」「棚」「照合」「工程」「パレット」「Zero2W」「購買」で記録の種類を絞ります。
6. 「‹ 配膳の場所へ」で配膳の場所に戻ります。

## よくある困りごととその場の対処

- 「記録はありません」と出たら、製造オーダーの番号を確かめて入れ直します。
- 購買の記録は製番と品番で結び付けているので、別の品物の記録が混ざることがあります。

## それでも直らないとき

画面右下の丸いボタンを押し、「お問い合わせ」から送ってください。
端末名と、何をしたら何が出たかを書くと早く直ります。
